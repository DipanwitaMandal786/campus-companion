# 🎓 Campus Companion

A full-stack **Campus Companion Platform** built for **Impetus Hackathon 2026**.

## 🚀 Problem Statement
Students face difficulty managing campus navigation, events, team formation, cafeteria queues, and communication with faculty using fragmented systems.

## 💡 Solution
Campus Companion provides a **single unified platform** for:
- Campus navigation
- Event & hackathon registrations
- Community discussions & mentoring
- Team formation
- Cafeteria queue management
- Secure authentication
- Admin monitoring

## 🧩 Key Features
- 🔐 Firebase Authentication (Login / Logout)
- 👤 Role-based access (Admin / Student)
- 📍 Campus Map module
- 🎉 Events & Hackathons module
- 💬 Community & Mentorship
- 🤝 Team Formation
- 🍔 Cafeteria Queue System
- 🤖 AI Assistant (extensible design)
- 🛠 Admin Dashboard

## 🛠 Tech Stack
**Frontend**
- HTML5
- CSS3
- JavaScript

**Backend**
- PHP
- MySQL
- XAMPP (Local server)

**Authentication**
- Firebase Authentication
